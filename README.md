# hux-huxLauncher

Простой и красивый лаунчер для управления сервисом **Zapret** (версия 1.9.8c).

Проект компилируется с помощью Nuitka не PyInstaller

## Возможности 

*   **Запуск стратегий:** Выбор и запуск любого `.bat` файла из папки с программой.
*   **Управление сервисом:** Установка, удаление и проверка статуса сервиса `zapret`.
*   **Настройки:** Открытие `service.bat` с удобной подсказкой по командам.
*   **Обновления:** Встроенная проверка новых версий на GitHub.
*   **Красивый интерфейс:** Тёмная тема.

## Установка и запуск 

1.  Скачайте последнюю версию `hux-huxLauncher.exe` со страницы [Releases](https://github.com/dimacmirnov41-netizen/hux-huxLauncher/releases).
2.  Скачайте версию 1.9.8c с официал страницы Flowseal кому лень вот : [тык](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.9.8c) 
3.  Поместите файл в папку с распакованным **Zapret** (рядом с `service.bat` и папками `bin`, `lists`, `utils`).
4.  Запустите `hux-huxLauncher.exe` от имени администратора.
