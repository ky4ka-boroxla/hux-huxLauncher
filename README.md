# hux-huxLauncher

Простой и красивый лаунчер для сервиса **Zapret** от Flowseal (версия 1.9.8c).
Собирается через Nuitka.

## Возможности

* **Запуск стратегий:** выбор и запуск любого `.bat` из списка, активная подсвечивается, есть кнопка остановки.
* **Избранное:** отмечай звёздочкой нужные стратегии, они уходят в отдельный блок сверху.
* **Управление сервисом:** установка, удаление и проверка статуса сервиса `zapret`.
* **Настройки:** открытие `service.bat` с подсказкой по командам.
* **Автообновление:** лаунчер сам качает новую версию, проверяет SHA-256 и заменяет себя.
* **Автозапуск с Windows:** один переключатель, окно при входе открывается свёрнутым.
* **Языки:** RU, EN, UA, BE и «брат».
* **Тёмная тема.**

## Установка и запуск

1. Скачай последнюю версию `hux-huxLauncher.exe` со страницы [Releases](https://github.com/ky4ka-boroxla/hux-huxLauncher/releases).
2. Запусти его и согласись на запрос UAC.

Zapret уже внутри, больше ничего качать не надо.

## Если ты экстремал

Если у тебя свой кастомный zapret, но с такой же структурой папок, как у [Flowseal](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.9.8c) (рядом `service.bat`, папки `bin`, `lists`, `utils`), то жми на кнопку с папкой 📁 в углу лаунчера и выбирай свою папку. Вернуться на встроенный zapret можно там же.

## Автозапуск

Переключатель в настройках создаёт задачу планировщика `hux-huxLauncher`, которая запускает лаунчер при входе с правами администратора. Выключаешь переключатель, задача удаляется.

## Антивирусы и SmartScreen

Exe не подписан, а у меня пока нет репутации, поэтому SmartScreen и часть антивирусов могут ругаться. Это ложные срабатывания. Проверить можно так:

* сверь SHA-256 файла с тем, что показывает GitHub на странице релиза
* посмотри отчёт на VirusTotal (ссылка в описании релиза)
* или собери сам: положи рядом исходники и `zapret`, запусти `build.bat`
